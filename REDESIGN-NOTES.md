# LM Manufacturing Website Redesign

This version keeps the existing Astro + CMS content architecture and applies a new visual direction.

## Main changes
- New editorial homepage hero with stronger LM brand presence.
- Large company logo retained and integrated into a cleaner sticky header.
- Rounded navigation treatment and stronger active states.
- New full-width company introduction layout with image-overlay statistics.
- New single-product spotlight for the current noodle product, with the package image as the central visual focus.
- New asymmetric factory/manufacturing section.
- New numbered manufacturing benefit rows.
- Refreshed news cards and contact call-to-action band.
- Owner/leadership section redesigned as a premium dark feature block.
- Single-product page presentation enlarged and simplified.
- Responsive redesign for tablet and mobile.
- Dark mode remains supported.

## Important
The owner portrait and approved owner biography still need to be replaced with real company-approved content.
The current product image can be replaced through the existing product content/CMS fields with the real noodle packaging photo.
