summary: ដឹកនាំប្រតិបត្តិការ IT ឱ្យមានស្ថិរភាព សុវត្ថិភាព និងគាំទ្រការងាររបស់ក្រុមផលិតកម្ម និងការិយាល័យបានល្អ។
responsibilities:
- គ្រប់គ្រង និងថែទាំហេដ្ឋារចនាសម្ព័ន្ធ IT របស់ក្រុមហ៊ុន រួមមានបណ្តាញ Wi‑Fi ម៉ាស៊ីនមេ CCTV កុំព្យូទ័រ ម៉ាស៊ីនបោះពុម្ព និងប្រព័ន្ធពាក់ព័ន្ធ។
- រៀបចំ និងអនុវត្តរចនាសម្ព័ន្ធបណ្តាញ VLAN គោលការណ៍ Firewall ការតភ្ជាប់អ៊ីនធឺណិត និងការគ្រប់គ្រងសន្តិសុខសាយប័រ។
- គ្រប់គ្រងគណនីអ្នកប្រើប្រាស់ សិទ្ធិចូលប្រើ ការដំឡើងកម្មវិធី ប្រព័ន្ធប្រតិបត្តិការ និងគោលការណ៍សន្តិសុខ IT។
- ត្រួតពិនិត្យម៉ាស៊ីនមេ NAS/ប្រព័ន្ធចែករំលែកឯកសារ ការបម្រុងទុកទិន្នន័យ ការការពារទិន្នន័យ និងផែនការស្ដារឡើងវិញ។
- តាមដានប្រព័ន្ធ IT និងដោះស្រាយបញ្ហាផ្នែក Hardware Software បណ្តាញ ម៉ាស៊ីនបោះពុម្ព និងការតភ្ជាប់។
- គ្រប់គ្រងទ្រព្យសម្បត្តិ IT បញ្ជីឧបករណ៍ អាជ្ញាបណ្ណកម្មវិធី ការធានា និងកាលវិភាគថែទាំ។
- សម្របសម្រួលជាមួយអ្នកផ្គត់ផ្គង់ និងអ្នកម៉ៅការផ្នែក IT សម្រាប់បណ្តាញ CCTV ខ្សែកាប ឧបករណ៍ និងគម្រោងប្រព័ន្ធ។
- គាំទ្រ និងថែទាំប្រព័ន្ធអាជីវកម្ម ដូចជា ERP ប្រព័ន្ធវត្តមាន ប្រព័ន្ធផលិតកម្ម និងកម្មវិធីការិយាល័យ។
- រៀបចំថវិកា IT សម្រង់តម្លៃ ផែនការគម្រោង របាយការណ៍ ឯកសារបច្ចេកទេស និងអនុសាសន៍ជូនគ្រប់គ្រង។
- ផ្តល់ការគាំទ្របច្ចេកទេស និងណែនាំបុគ្គលិក ដើម្បីរក្សាប្រព័ន្ធ IT ឱ្យមានសុវត្ថិភាព ស្ថិរភាព និងអាចប្រើប្រាស់បាន។
- រៀបចំ និងអនុវត្តនីតិវិធី ស្តង់ដារ និងគោលការណ៍ IT នៅទូទាំងក្រុមហ៊ុន។
- វាយតម្លៃបច្ចេកវិទ្យាថ្មី និងស្នើការកែលម្អ ដើម្បីបង្កើនប្រសិទ្ធភាព សន្តិសុខ និងភាពបន្តរបស់អាជីវកម្ម។
requirements:
- បញ្ចប់បរិញ្ញាបត្រផ្នែកព័ត៌មានវិទ្យា វិទ្យាសាស្ត្រកុំព្យូទ័រ វិស្វកម្មកុំព្យូទ័រ ឬជំនាញពាក់ព័ន្ធ។
- មានបទពិសោធន៍ ៣–៥ ឆ្នាំ ឬច្រើនជាងនេះ ក្នុងការគាំទ្រ IT គ្រប់គ្រងប្រព័ន្ធ បណ្តាញ ឬហេដ្ឋារចនាសម្ព័ន្ធ។
- មានចំណេះដឹងល្អអំពី LAN/WAN, VLAN, Wi‑Fi, Routing, Switching, VPN និង Firewall។
- មានបទពិសោធន៍ជាមួយ Windows Server, Active Directory, Microsoft 365 និងការគ្រប់គ្រងសិទ្ធិអ្នកប្រើប្រាស់។
- មានចំណេះដឹងអំពីម៉ាស៊ីនមេ NAS ប្រព័ន្ធ Backup ការចែករំលែកឯកសារ និងការស្ដារប្រព័ន្ធក្រោយមានបញ្ហា។
- មានបទពិសោធន៍គ្រប់គ្រង CCTV ម៉ាស៊ីនបោះពុម្ព កុំព្យូទ័រ Access Control និងឧបករណ៍ IT ផ្សេងៗ។
- យល់ដឹងអំពី Cybersecurity, Endpoint Protection, Access Control និងគោលការណ៍សន្តិសុខ IT។
- អាចគ្រប់គ្រងគម្រោង IT អ្នកផ្គត់ផ្គង់ សម្រង់តម្លៃ ថវិកា និងការទិញឧបករណ៍។
- មានជំនាញដោះស្រាយបញ្ហា និងវិភាគបញ្ហាបានល្អ។
- មានជំនាញរៀបចំឯកសារ របាយការណ៍ ទំនាក់ទំនង និងការគ្រប់គ្រងក្រុម។
- អាចគាំទ្រ ERP និងប្រព័ន្ធអាជីវកម្មផ្សេងៗ គឺជាអាទិភាពបន្ថែម។
- វិញ្ញាបនបត្រ ដូចជា CCNA, Microsoft, Fortinet, MikroTik ឬ CompTIA គឺជាអាទិភាពបន្ថែម។
