# Default Language Update

- First visit to the main site `/` now opens the Khmer version `/kh`.
- The language switch from the Khmer homepage opens English with `/?lang=en`.
- The browser remembers an English choice so returning to `/` will stay English for that user.
- Visiting any `/kh/...` page stores Khmer as the preferred language again.
- Existing English and Khmer URLs remain unchanged.
